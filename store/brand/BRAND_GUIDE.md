# ANGELBYTE — Brand Guide (draft 1)

**Tagline:** Heaven on dial-up
**Positioning:** Premium Y2K-vintage streetwear for 17–29 year olds, printed on demand in the USA.

## Name status
Lead: **ANGELBYTE**. A quick web search found no apparel brand using it.
Backups: Pixel Halo, Low Battery Club.
Dropped because of conflicts: Static Angel, Dialtone, AWAY MSG.
**Before spending money:** run a USPTO Trademark Search, check that angelbyte.com and the @angelbyte handles on IG/TikTok are free, and file a trademark in class 25 (clothing).

## Logos (`logos/`)
- **A · Chrome wordmark:** main logo for the site header, chest prints and the neck label
- **B · Angel cursor:** icon for the favicon, social profile picture, hat embroidery, pins and phone charms
- **C · Burned-CD badge:** for stickers, packaging seals, hang tags and the back neck print
Drafts use web fonts. Convert the text to outlines before sending files to print or embroidery.
