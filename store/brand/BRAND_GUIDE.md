# SOFT HOURS: Brand Guide (draft 2)

**Tagline:** Stay in. Stay soft.
**Positioning:** Cozy loungewear at mid-range prices ($30–60) for 17–29 year olds, printed on demand in the USA.
*(Replaces the earlier Y2K retro direction, ANGELBYTE, which is kept in git history.)*

## Name status
Lead: **SOFT HOURS**. A quick web search found no clothing brand using it.
Backups: Mellow Den, Stay Soft.
Dropped because of conflicts: Duvet Day (bedding line), Slow Morning Club (2025 trademark filing), Hush Hour (Hush UK), Snug Studio (existing label).
**Before spending money:** run a USPTO Trademark Search, check that softhours.com and the @softhours handles on IG/TikTok are free, and file a trademark in class 25 (clothing).

## Logos (`logos/`): combo system (chosen)
- **Lockup (B + A)** `softhours-lockup.svg`: site header, email header, packaging, hang tag front
- **A · Puffy wordmark:** rounded lowercase "soft hours" with a butter moon; for the site header, prints and neck label
- **B · Cloud clock:** icon for the favicon, social profile picture, beanie/cap embroidery and sock cuffs
- **C · Stay In Club label:** sage stitched label for the back neck, hang tags and packaging stickers
Drafts use web fonts. Convert the text to outlines before sending files to print or embroidery.

## Voice
Warm, calm, a little funny. Lowercase on social. Sounds like a friend telling you to take a break.
- cancel your plans. we made sweats for that.
- soft hours are now open. no closing time.
- made to order, so it's made just for you. no warehouse, no waste.
- the cloud set: for 8am classes and 8pm naps.
- reminder: rest is productive. so is this hoodie.
